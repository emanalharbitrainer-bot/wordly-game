# WORDLY · وردلي

لعبة كلمات ثنائية اللغة (عربي / English) — Vite + React + TypeScript، والخادم على Supabase.

- `npm run build` يبني القواميس ثم الواجهة.
- كلمات التحدي اليومي محفوظة في قاعدة البيانات فقط ولا توجد في هذا المستودع.
- متغيرات البيئة المطلوبة (قيم عامة): `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`.
